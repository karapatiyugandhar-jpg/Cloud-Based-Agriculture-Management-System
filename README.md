# Cloud-Based Agriculture Management System

## Features
- Agriculture dashboard
- Crop management
- Farm task planner
- REST API using Node.js + Express
- Responsive web interface
- Cloud-ready project structure

## Run locally
1. Install Node.js.
2. Open PowerShell/Command Prompt inside this folder.
3. Run:
   npm install
4. Then:
   npm start
5. Open:
   http://localhost:5000

If PowerShell blocks `npm.ps1`, use:
npm.cmd install
npm.cmd start

## Suggested cloud deployment
This project can be deployed to services such as Render, Railway, Azure App Service, or AWS. For a real production cloud system, add a managed database, authentication, HTTPS, backups, and environment variables.
